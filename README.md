# PwdMgr

本地离线密码管理器（Windows / C# / WinUI 3）。密码库是一个加密文件，钥匙文件由你自己保管；程序运行时不联网，也不会上传任何数据。

## 这个项目做什么

![主界面](docs/ui/vault.png)

- **密码管理**：新增、编辑（字段直接可改）、删除；删除进回收站，可恢复或彻底删除，超过 30 天自动清除
- **加密存储**：密码库用 AES-256-GCM 加密，数据密钥由钥匙文件里的 RSA-3072 私钥封装；保存时原子写入、读回校验，并自动保留 `.bak`
- **密码生成器**：独立窗口 + 密码框旁的骰子按钮；可设长度、字符类型、排除易混淆字符、自定义字符
- **强度提示**：密码框下方显示弱 / 中等 / 强 / 很强与估算比特数
- **剪贴板**：一键复制用户名或密码，30 秒后自动清空，并尽量排除剪贴板历史
- **搜索、备份、自检**：按标题/用户名/网址/备注搜索；可创建备份、检查密码库、从备份恢复
- **自动上锁**：闲置 5 分钟或系统锁屏自动上锁；上锁后需要重新选择钥匙文件
- **主题**：跟随系统，或手动切换浅色 / 深色
- **绿色版**：解压即用，不需要安装，不写注册表

## 本地编译

环境要求：

- Windows 10 1809+ / Windows 11
- .NET SDK 8.0 或更高
- Visual Studio 2022 / 2026，安装「.NET 桌面开发」工作负载（WinUI 工程依赖 VS 自带的 Appx MSBuild 任务，`dotnet build` 编译不了界面工程）

编译：

```cmd
build.cmd
```

脚本会用 `vswhere` 找到 VS 的 MSBuild 再编译整个解决方案。PowerShell 执行策略允许时也可以直接用 `.\build.ps1`。

产物在：

```
src\PwdMgr.App\bin\x64\Debug\net8.0-windows10.0.19041.0\win-x64\PwdMgr.exe
```

直接运行，或带参数打开指定密码库：

```cmd
PwdMgr.exe
PwdMgr.exe "D:\我的密码库.pwdb" "D:\我的密码库.key"
```

> 开发机若对未签名程序有降权限制，请把产物复制到仓库目录之外再运行（原因见 `docs/技术方案-v1.md` 第 19 节）。

跑单元测试：

```powershell
dotnet tests/PwdMgr.Core.Tests/bin/Debug/net8.0/PwdMgr.Core.Tests.dll
```

打包正式发布包（自包含，目标机无需装 .NET 或 Windows App SDK）：

```cmd
package.cmd
```

版本号只在 `Directory.Build.props` 的 `<Version>` 里维护，打包脚本会自动读取。输出：

```
dist\PwdMgr-1.0.0-win-x64\                    解压即用的程序目录
dist\PwdMgr-1.0.0-win-x64.zip                 发布包（约 67 MB，内含同名顶层目录）
dist\PwdMgr-1.0.0-win-x64.zip.sha256          SHA-256 校验和
```

包内包含 `PwdMgr.exe`、依赖 DLL、`PwdMgr.pri`、`README.txt`、`README.md`、`LICENSE` 与 `LICENSE.GPL-3.0`。

## 如何使用

1. **创建密码库**：双击 `PwdMgr.exe` → “创建新密码库” → 选择或直接输入密码库文件与钥匙文件路径 → 记下弹出的钥匙指纹 → 把钥匙文件另存一份到别处
2. **打开**：选择或输入 `.pwdb` 与 `.key`，也可以把文件直接拖进窗口
3. **编辑条目**：字段直接改，有改动时底部出现“保存修改 / 放弃修改”；切换条目、搜索、上锁、关窗前会自动保存
4. **删除条目**：列表项右侧红色“删除”，确认后进入回收站，可在回收站恢复或彻底删除
5. **生成密码**：密码框旁的骰子按钮，或工具栏“生成器”；调整规则后点“生成”才会重新生成
6. **上锁 / 解锁**：点右上角“上锁”，或闲置 5 分钟自动锁定；上锁后需重新选择钥匙文件
7. **备份与恢复**：工具栏“更多” → 创建备份 / 检查密码库 / 从备份恢复
8. **主题**：右下角或工具栏最右的齿轮，可选跟随系统 / 浅色 / 深色
9. **快捷键**：`Ctrl+N` 新建、`Ctrl+G` 生成器、`Ctrl+F` 搜索、`Ctrl+L` 上锁、`Ctrl+S` 保存

> 钥匙文件丢失后密码库无法打开，也没有找回途径。建议把密码库、钥匙文件、备份分别放在不同位置。
